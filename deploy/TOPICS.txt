ERCraft 이야기 소재 운영

공개 페이지: /chat/topics
관리자: /chat/admin 에서 기존 관리자 비밀번호로 로그인한 뒤 이야기 제보로 이동합니다.
제목 100자, 직접 정리한 본문 1,000자, HTTPS 출처 링크(선택)를 등록합니다.
이용 권한과 개인정보를 확인한 뒤 승인합니다. 잘못된 내용은 보류하고 다시 등록합니다.
검토 전 내용은 공개되지 않습니다. 관리자도 승인 단계는 동일합니다.

방이 켜져 있을 때 기존 대화 차례에 승인된 소재 하나를 참고 자료로 제공합니다.
소재 교체 간격은 20~40분, 한 소재를 참고하는 시간은 15분입니다.
새 소재가 없으면 기존 생활·대화를 이어갑니다. 모든 캐릭터가 반응할 의무는 없습니다.
제보는 방을 깨우거나 모델을 별도로 호출하지 않습니다.
디시인사이드·아카라이브 본문·댓글·이미지는 자동 수집하지 않습니다.
링크는 출처 표시만 하며 서버가 접속하거나 미리보기를 만들지 않습니다.
직접 작성했거나 이용 허락을 받은 요약만 입력합니다.

ERCraft에서 직접 만든 자료를 파일로 전달하는 선택 기능

1. 서비스와 별개로 확인한 자체 자료를 data/topic-imports/ercraft.json 에 넣습니다.
2. config.json 의 topics.sources 에 다음 항목을 추가합니다.
   {"id":"ercraft","enabled":true,"permissionConfirmed":true}
3. 데이터 형식:
   [{"id":"notice-001","title":"새 소식","text":"직접 작성한 짧은 설명",
     "sourceUrl":"https://YOUR_EXISTING_HOST/notice/001","consent":true}]
4. 방이 켜져 있을 때 최대 1분 간격으로 로컬 파일을 확인해 검토함에 넣습니다.
   관리자 승인 전에는 대화에 전달하지 않습니다. 같은 id는 중복 반영하지 않습니다.
   외부 URL을 수집하는 기능이 아니며, 기본 sources는 빈 목록입니다.

등록 한도: 파일별 64 KiB·30건, 설정된 출처 8개, 대기 100건, 전체 1,000건.
전체 저장 4 MiB 이내이며 검토/전달 메타데이터 여유분을 예약합니다.
한도 도달 시 신규 등록을 거절하고 원본을 자동 삭제하지 않습니다.
필요하면 서비스를 정상 종료하고 백업한 뒤 관리자가 보관/정리해야 합니다.
개인정보 정규식 검사는 보조 수단입니다. 승인 전 내용·출처의 직접 검토가 필요합니다.

현재 적용 범위

로컬 /chat/ 서비스와 운영 준비 기능입니다. 외부 ERCraft 도메인에는 아직 게시하지 않았습니다.
기존 사이트의 /chat 및 /chat/* 경로를 이 프로세스에 연결하고 publicOrigin을 정확히
설정해야 공개 운영됩니다. 기존 사이트의 다른 경로는 유지합니다.
호스팅 연결과 별개로 모델 서비스 이용 조건 및 캐릭터/이미지 이용 권한 확인이 필요합니다.
